Xeory ベーステーマ - シンプルで使いやすいWordPressテーマ

== Description ==

XeoryBaseは、バズ部が開発したシンプルで使いやすいWordPressテーマです。
ブログやコーポレートサイトに最適化されており、レスポンシブデザインに対応しています。

主な特徴:
* レスポンシブデザイン（デスクトップ、タブレット、スマートフォン対応）
* カスタマイザー対応
* SEO最適化
* ソーシャルメディア連携
* カスタム投稿タイプ対応
* 多言語対応（翻訳準備済み）
* 高速表示
* アクセシブルなデザイン

== Installation ==

1. WordPress管理画面から「外観」→「テーマ」→「新規追加」→「テーマのアップロード」を選択
2. テーマファイル（zipファイル）をアップロード
3. テーマを有効化

または

1. `/wp-content/themes/` ディレクトリにテーマフォルダをアップロード
2. WordPress管理画面から「外観」→「テーマ」でテーマを有効化

== Frequently Asked Questions ==

= このテーマはレスポンシブ対応ですか？ =

はい、XeoryBaseは完全にレスポンシブ対応しています。デスクトップ、タブレット、スマートフォンで最適に表示されます。

= カスタマイズは可能ですか？ =

はい、WordPressのカスタマイザーを通じて様々な設定が可能です。また、CSSの追加によるカスタマイズにも対応しています。

= 子テーマは必要ですか？ =

テーマのアップデート時にカスタマイズが失われることを防ぐため、子テーマの使用を強く推奨します。
